## 贡献新报告

1. 在对应课程文件夹下新建"实验名称"子文件夹（没有该课程就新建课程文件夹）；
2. 图片按 `01-封面.jpg`、`02-正文-上.jpg`… 顺序命名放入；
3. 在本 README 的目录表里加一行。

## 关于隐私

上传前已对扫描件做以下处理，如有遗漏欢迎提 issue：

1. **封面个人信息**：学院、姓名、班级、学号四项已用不透明色块遮挡（打马赛克不算遮挡，放大后仍可辨认，因此一律改为实心遮挡）；
2. **教师签字**：红笔签名按像素级抹除，只去笔迹、不动表格与黑字数据；
3. **照片元数据**：清除全部 EXIF（设备型号、拍摄时间等），并统一压缩到长边 2400 px；
4. 原始材料一律不上传，仓库内只有处理后的图片。

自己上传时请照此办理：遮挡要**不透明**，别只打码。
